# Contributing to Airbase 🚀

Thank you for considering contributing to Airbase! Open source thrives on community contributions.

## How to Contribute

1. **Fork the Repository**: Click the 'Fork' button at the top right of this repository.
2. **Clone your Fork**:
   ```bash
   git clone https://github.com/your-username/airbase.git
   cd airbase
   ```
3. **Create a Feature Branch**:
   ```bash
   git checkout -b feature/amazing-feature
   ```
4. **Test your Changes**: Ensure `start.bat` launches clean without errors.
5. **Commit & Push**:
   ```bash
   git commit -m "Add amazing feature"
   git push origin feature/amazing-feature
   ```
6. **Open a Pull Request**: Submit a PR describing your changes.

## Code Style & Guidelines
- Keep CSS variables inside `static/css/style.css`.
- Ensure all new features work seamlessly on both mobile touchscreens and desktop.
- Maintain zero external cloud dependencies (keep all transfers local LAN only).
